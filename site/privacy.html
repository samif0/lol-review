Privacy policy

Last updated: 2026-10-10

Revu is a Windows desktop app. Your review data, game history, notes, objectives, and clips live on your machine. Revu's server holds only what it needs to run its online features: the email address and session you use to sign in, clips you choose to share and their transcripts (deleted after 3 days), and daily transcription usage counts (kept for 7 days). This page explains exactly what Revu reads, what it stores, and what (if anything) leaves your computer.

What Revu stores locally

Revu writes to two folders on your machine:

  • %LOCALAPPDATA%\LoLReviewData\: your data, SQLite database (revu.db), config, safety backups, captured clips and narration recordings. Persists across reinstalls.
  • %LOCALAPPDATA%\LoLReview\: app binaries and updater files. Replaced on each update; doesn't contain user data.

Crash logs and startup logs land in %LOCALAPPDATA%\Revu\. The Velopack updater log is at %LOCALAPPDATA%\LoLReview\velopack.log. These contain stack traces, version info, and timing data. No Riot account credentials, no other users' data.

What leaves your machine

Revu makes outbound network calls to a small number of services. Nothing else.

  • Revu's Cloudflare Worker (revu-proxy.lol-review.workers.dev, with shared links served from clips.revu.lol): handles Riot lookups, sign-in, clip sharing uploads, and narration transcription. For Riot lookups it forwards Match-V5 requests using a server-side API key; your Riot ID, region, and match IDs flow through. Clips you share and narration you record while signed in are uploaded here; see Shared clips and narration. The rest of your local game data does not leave your machine. The Worker logs request metadata (timestamps, status codes) for rate limiting and abuse prevention; it does not log request bodies.
  • Email sign-in: when you sign in, your email address is sent to Revu's Worker, which stores it with your account and sign-in session. The sign-in code is emailed to you through an email delivery provider (Resend), which receives your email address only to send that message.
  • Riot Games' Match-V5 API (via the proxy above): read-only, returns the same public match data you can see on op.gg.
  • Shared clip links (clips.revu.lol): only serves the links for clips you share. See Shared clips and narration.
  • GitHub Releases (api.github.com, github.com): for the auto-updater. The app checks for new versions on launch and downloads them when available. GitHub sees the download as a normal anonymous release fetch.
  • CommunityDragon (raw.communitydragon.org): read-only static champion data (icons, ability info). Cached on disk after the first fetch.
  • Local LCU connection. Revu talks to your League client over 127.0.0.1 using credentials the LCU exposes locally. This traffic never leaves your machine.

Shared clips and narration

  • When you share a clip, the clip and its transcript are uploaded to Revu's server so the link works. They are stored for 3 days, then deleted. Anyone with the link can watch the clip and read its transcript during that time. Deleting the clip in the app also removes the shared copy as soon as Revu can reach its server while you are signed in; otherwise the shared copy expires after 3 days.
  • When you are signed in, narration audio you record over a clip is sent to Revu's server and processed by Cloudflare Workers AI only to create a transcript. The audio is not kept after the transcript is made.
  • Everything else stays on your PC: your games, notes, VODs, clips you have not shared, and your narration recordings.

What we do not collect

  • No third-party analytics (no Google Analytics, no Mixpanel, no Sentry).
  • No Revu telemetry events, usage tracking, or feature pings.
  • No sale or sharing of any data with third parties.
  • No advertising tracking or A/B-testing instrumentation.
  • No remote feature flags that report your behavior back to us.

The desktop app runs on the Overwolf Electron runtime. Turning off Overwolf's optional analytics still leaves the minimal runtime telemetry that Overwolf requires, which is covered by Overwolf's own privacy policy.

If we ever add optional, anonymous crash telemetry in a future version, it will be off by default, clearly labeled in the app's settings, and announced in that version's release notes before it ships.

The website itself

This site is hosted on Cloudflare Pages. Cloudflare logs request metadata (IP, User-Agent, timestamp) per their standard infrastructure logging. See Cloudflare's privacy policy. We do not run any analytics on this site.

The web review tool on this site's home page stores your recent searches, cached match lists, review notes, and the name and size of the file you attached in your browser's local storage. It does not upload ROFL files, VODs, or other media. Clearing your browser data for this site removes that local web review data.

Your rights

Because Revu's data lives on your machine, deleting your data means uninstalling Revu and removing the %LOCALAPPDATA%\LoLReviewData\ folder. Shared clips and their transcripts are deleted from Revu's server after 3 days, or sooner if you delete the clip in the app while signed in and Revu can reach its server. For the web review tool, delete this site's browser data to remove the local web copy.

Changes to this policy

Material changes will be reflected in the Last updated date above and called out in the release notes for the version that introduces them.
